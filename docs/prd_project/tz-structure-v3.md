**Варианты способа подачи для рассмотрения:**
- **Идеальный:** навалом в стандартной таре, манипулятор перемещает тару по хранилищу для ускорения раскладки
- **Гибридный (рекомендуемый):** рука на транспортёре раскладывает из навала в спец-контейнер в удобных для захвата положениях → манипулятор перемещает спец-контейнер по хранилищу и раскладывает предметы из спец-контейнера по пеналам. Преимущества: легче реализовать, ускоряет загрузку, повышает надёжность разбора
- Оператор выкладывает на конвейер / в зону загрузки
